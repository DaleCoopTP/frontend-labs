## Лабораторная работа №1

`lab1/index.html` — семантическая HTML-разметка без CSS и JavaScript.

Сохранены `header`, `main`, `footer`, `nav`, `section`, `article`, `aside`,
заголовки `h1`–`h3`, списки `ul` и `ol`, `blockquote`, `cite`, `strong`, `em`,
`del`, `ins`, `figure`, `figcaption`, формы с `fieldset`, `legend` и `label`,
а также `time`, `address` и `dl`.

## Лабораторная работа №2

`lab2/index.html` — продолжение первой работы с оформлением в `lab2/styles.css`.
Содержимое и семантические элементы первой работы сохранены. Добавлены контейнеры
для расположения карточек и полей, классы и декоративные SVG-иконки.

### Методология

Используется БЭМ: самостоятельные блоки `hero`, `search`, `review-card`,
элементы `hero__title`, `search__input` и модификаторы `button--secondary`,
`request-form__field--problem`. Классы описывают назначение элементов.
БЭМ выбран, чтобы изолировать оформление блоков, повторно использовать карточки
и кнопки и сохранять невысокую специфичность селекторов.

### Оформление

- Цвета, основные отступы, радиус и максимальная ширина заданы в `:root`.
- Размеры шрифта заданы в `rem`, крупные заголовки используют `clamp()`.
- Шрифт: `Open Sans`, затем `Arial`, `Helvetica`, `sans-serif`.
- Блочная модель `border-box` учитывает рамки и внутренние отступы в ширине.
- Grid используется для секций, карточек и форм, Flexbox — для навигации и действий.
- Расстояния между элементами flex- и grid-контейнеров заданы через `gap`.
- Абсолютное позиционирование размещает кнопку поиска внутри поля;
  её контейнер имеет `position: relative`, а поле резервирует место справа.
- Для ссылок, кнопок и полей предусмотрены `:hover` и `:focus-visible`.
- Медиазапросы на `68rem`, `48rem` и `30rem` перестраивают колонки.
- Пользовательский `prefers-reduced-motion` отключает переходы.

Стили организованы от базовых правил к блокам и адаптивным переопределениям.
Более поздние медиазапросы меняют компоновку через каскад. Размеры текстовых
блоков определяются содержимым. JavaScript, CSS-фреймворки, препроцессоры,
inline-стили, `!important` и CSS-селекторы по идентификатору не используются.

## Лабораторная работа №3

`lab3/index.html` продолжает вторую работу. Базовое оформление подключается из
`lab2/styles.css`, стили интерактивных элементов находятся в `lab3/styles.css`.

В разделе «Ваши отзывы» можно указать имя, оценку консультации и текст отзыва,
добавить запись, найти отзывы по имени или тексту и удалить выбранный отзыв.
Проверяются обязательные поля, длина текста, оценка и ввод из пробелов.
После добавления форма очищается. Поиск вычисляет отображаемый список,
не изменяя исходные данные, а сброс возвращает все оставшиеся записи.

Исходный массив автоматически сохраняется в `localStorage` под ключом
`100-lawyers:lab3:reviews` и восстанавливается после перезагрузки. Без сохранения
список пуст. Пустой массив после удаления всех отзывов также сохраняется.
Ошибки JSON, структуры, доступа и записи выводятся на странице; раздел
продолжает работать в текущей вкладке. Пользовательский текст выводится
через `textContent`, каждый отзыв получает сохраняемый уникальный идентификатор.

### Модули

- `js/main.js` — точка входа, подключённая через `script type="module"`.
- `js/reviews-model.js` — массив объектов, проверка данных, добавление, удаление и поиск без DOM.
- `js/reviews-storage.js` — чтение и запись JSON в хранилище с обработкой ошибок.
- `js/reviews-view.js` — создание карточек и отображение сообщений.
- `js/reviews-controller.js` — обработчики событий, связывающие данные и отображение.
- `js/slider.js` — общая функция `initializeSlider(root)` для слайдеров.

В макете предусмотрен слайдер отзывов клиентов. Он переключается стрелками и
точками по кругу, смещая начало текущей группы на один отзыв. На широком экране
видны три карточки, на планшете две, на телефоне одна. Количество карточек
задаётся CSS-переменной. Активная точка соответствует первой карточке группы.
Состояние хранится в замыкании каждой инициализации; несколько экземпляров
работают независимо. Для единственного слайда стрелки блокируются.

Сохранены БЭМ, адаптивность, управление с клавиатуры и видимый фокус.
Библиотеки, фреймворки, TypeScript, обработчики в HTML и сборщик не используются.

### Проверка

Проверки модели и хранилища на Node.js 20 или новее:

```sh
cd lab3
npm test
```

Установка зависимостей не нужна. Браузерные проверки доступны после запуска
HTTP-сервера по адресу http://127.0.0.1:8080/lab3/tests/browser.html.
Они проверяют формы, поиск, удаление, восстановление, ошибки хранилища,
безопасный вывод текста, независимость слайдеров и отсутствие повторных
обработчиков. Проверки используют отдельное тестовое хранилище и не меняют
сохранённые отзывы основной страницы.

## Запуск

ЛР1 и ЛР2 можно открыть напрямую в браузере. Для ЛР3 нужен локальный HTTP-сервер:
при открытии через `file://` ES Modules не работают. Сборка и установка
зависимостей не нужны.

Для запуска через локальный сервер из корня репозитория:

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

Адрес второй работы: http://127.0.0.1:8080/lab2/.

Адрес третьей работы: http://127.0.0.1:8080/lab3/.
