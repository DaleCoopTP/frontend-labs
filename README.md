## Лабораторная работа №1

`lab1/index.html` — семантическая HTML-разметка без CSS и JavaScript.

Сохранены `header`, `main`, `footer`, `nav`, `section`, `article`, `aside`,
заголовки `h1`–`h3`, списки `ul` и `ol`, `blockquote`, `cite`, `strong`, `em`,
`del`, `ins`, `figure`, `figcaption`, формы с `fieldset`, `legend` и `label`,
а также `time`, `address` и `dl`.

## Лабораторная работа №2

`lab2/index.html` — продолжение первой работы с оформлением в `lab2/styles.css`.
Содержимое и семантические элементы первой работы сохранены. Добавлены контейнеры
для расположения карточек и полей, классы и декоративные SVG-иконки.

### Методология

Используется БЭМ: самостоятельные блоки `hero`, `search`, `review-card`,
элементы `hero__title`, `search__input` и модификаторы `button--secondary`,
`request-form__field--problem`. Классы описывают назначение элементов.
БЭМ выбран, чтобы изолировать оформление блоков, повторно использовать карточки
и кнопки и сохранять невысокую специфичность селекторов.

### Оформление

- Цвета, основные отступы, радиус и максимальная ширина заданы в `:root`.
- Размеры шрифта заданы в `rem`, крупные заголовки используют `clamp()`.
- Шрифт: `Open Sans`, затем `Arial`, `Helvetica`, `sans-serif`.
- Блочная модель `border-box` учитывает рамки и внутренние отступы в ширине.
- Grid используется для секций, карточек и форм, Flexbox — для навигации и действий.
- Расстояния между элементами flex- и grid-контейнеров заданы через `gap`.
- Абсолютное позиционирование размещает кнопку поиска внутри поля;
  её контейнер имеет `position: relative`, а поле резервирует место справа.
- Для ссылок, кнопок и полей предусмотрены `:hover` и `:focus-visible`.
- Медиазапросы на `68rem`, `48rem` и `30rem` перестраивают колонки.
- Пользовательский `prefers-reduced-motion` отключает переходы.

Стили организованы от базовых правил к блокам и адаптивным переопределениям.
Более поздние медиазапросы меняют компоновку через каскад. Размеры текстовых
блоков определяются содержимым. JavaScript, CSS-фреймворки, препроцессоры,
inline-стили, `!important` и CSS-селекторы по идентификатору не используются.

## Запуск

Откройте `lab2/index.html` в браузере. Сборка и установка зависимостей не нужны.

Для запуска через локальный сервер из корня репозитория:

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

Адрес второй работы: http://127.0.0.1:8080/lab2/.
