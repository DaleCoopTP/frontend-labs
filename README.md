# Лабораторная работа №1. Средства гипертекстовой разметки документа

**ФИО:** `Гришин Матвей Максимович`  
**Группа:** `М3306`

## Тема

Семантическая HTML-разметка страницы сервиса юридической помощи «100 Юристов».

В работе воспроизведена содержательная структура макета: шапка и навигация, горячая линия,
способы получения консультации, преимущества сервиса, отзывы клиентов, список юристов,
форма вопроса и раздел со справочными материалами.

- `header`, `main`, `footer`;
- `nav`;
- `section`;
- `article`;
- `aside`;
- `h1`–`h3`;
- `p`;
- `ul` и `ol`;
- `blockquote` и `cite`;
- `strong`, `em`, `del`, `ins`;
- `figure`, `figcaption`;
- `form`, `fieldset`, `legend`, `label`, `input`, `textarea`, `button`;
- `time`, `address`, `dl`, `dt`, `dd`.
